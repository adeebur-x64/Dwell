# Dwell

Ever wondered how much time you've spent using your computer this day and what applications you used the most?   

<p style="text-align: center; font-size: 16px;"><b>Dwell</b> is here to help you track your screen time and productivity.</p>

---

## 🌟 Features
- Daily Screen Time Tracking
- Week Total and Daily Average Screen Time Monitoring
- Detailed insights on how much time was spent using a specific application
- **More to come!**

---

## ✨ Where was AI used?
`AI was used to get the Google's Material You 3 Design components. The design itself is hand made. However, the components (like the buttons) were extracted from Google's Docs by AI (Gemini 3.8 Flash). AI was also used to help in the core part of tracking the time since it involved a lot of desktop specific JavaScript.`
